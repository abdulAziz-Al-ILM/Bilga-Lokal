# Bilga UX 2.0 owner review, November 19, 2026

Habits, Finance, Experiences and Books have the same folder browser, with nested navigation, search, sorting, icons, colors, counts, trash and restoration. Legacy Books shelf memberships migrate to folders without rewriting book payloads. A folder move changes an encrypted reference to the existing item. A Finance reference contains the journal ID and original transaction ID. Amounts, accounts, currencies, debt links, ledger revisions and reconciliation remain intact. Deleted folders hide their subtree from folder navigation while keeping records accessible in the module. Notes database capability is 21 and portable content containing these changes uses version 19. Existing portable formats remain supported.

Finance opens on its selected journal balance, today’s expenses, current month income and expenses, recent entries, actual spending categories and planned payments. Multiple journals in a currency can show the exact corresponding total. Each other currency remains separate. The quick expense and income forms ask for amount, category, optional counterparty and note. Account and date are available under Advanced options. Saving a new category together with an expense is atomic. Category labels can change while the original key remains attached to transactions and plans. In-use categories can be archived and restored. All Features opens accounts, planning, categories, folders, attachments, export and other transaction types.

Quantitative habit cards show stored amount, historical target, unit, current percentage, remaining quantity and proportional progress. Increment and decrement commit against the current saved amount. The calendar shows actual quantities, with the day editor retaining historical notes. Binary habits keep a single completion toggle.

The home bell opens upcoming, due, overdue and completed or delivered items. New optional alerts are off by default and configured by module. Android receives only scheduling policy, stable source references and generic titles. Actual task reminders keep their existing dismissal and completion behavior. Optional reading and reflection reminders use civil times. Finance planning alerts require explicitly enabled preferences and never post transactions. Android notification permissions and alarm restrictions still apply.

Voice routes confirmed questions to actual tasks, reminders, habits, Notes, Experiences, folder memberships, weekly spending or the saved book location. Results stay visible and Android reads a bounded excerpt with an installed voice in the selected language. The output bridge restricts personal text to voices the Android engine identifies as embedded. Playback can stop, repeat or change speed. Unsupported voices display the result and reason. Existing push-to-talk, recognition correction and confirmation for financial writes remain in place.

Finance now fetches thin journal rows and processes only the selected ledger for its dashboard. Large ledger computation runs in an isolate, history rows build on demand, and search is debounced. Habit quantity updates refresh one row and avoid the old 28-button grid on every card. Reminder mirror writes and scheduling run off Android’s main thread. Startup runs independent initialization work concurrently. Profile-only instrumentation measures frame percentiles and scoped startup, query and PDF opening times.
